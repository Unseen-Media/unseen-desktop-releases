# Unseen Media — Desktop App Downloads

Native desktop client for the family Unseen Media server (Windows).

## Install

**[Download the latest installer](https://github.com/Unseen-Media/unseen-desktop-releases/releases/latest/download/UnseenMedia-Setup.exe)** and run it — per-user install, no admin rights needed.

Sign in with your Unseen Media account. The app keeps itself up to date automatically (updates install in the background, ~1 second restart).

## Notes

- Windows 10/11, 64-bit.
- Linux (Ubuntu 22.04+) builds are distributed separately as a tarball — ask Bogdan.
